# トップページ（examination app）

サイトのトップページ（`/`）となるReact（Vite）アプリ（[Issue #82](https://github.com/bamiyanapp/examination/issues/82)）。

`/top/`でのプレビュー確認を経て、正式なトップページとして採用した。既存の各ページ（React化済み・MkDocs双方）へのリンク一覧を提供する。

見た目はBootstrap 5.3（[Issue #114](https://github.com/bamiyanapp/examination/issues/114)、examination#308でdaisyUIから移行済み）で整えている。

## ローカル確認

```
npm install
npm run dev
```

## 検証

```
npm run lint
npm run test
npm run build
```
